# Description
- Summary statistics are single values that summarize over a whole dataset
- We need to be careful when using summary statistics
	- Summary statistics can be misleading
	- Reducing the expressiveness of a full dataset to single values is a massive reduction in [[Dimension|Dimensionality]]
- Examples
	- [[Mean]]
	- [[Median]]
	- [[Mode]]
	- [[Variance]]
	- [[Standard Deviation]]
	- [[Range]]
	- [[Quartile]]
	- [[Interquartile Range]]

# Anscombes Quartet
[Anscombes Quartet](https://en.wikipedia.org/wiki/Anscombe%27s_quartet) is an example of four datasets with the same [[Mean]], [[Median]], [[Mode]], [[Linear Regression]] lines, [[Variance]], and [[Correlation]]. The datasets visually are very clearly are very different. The quartet is a strong example of summary statistics being misleading.
