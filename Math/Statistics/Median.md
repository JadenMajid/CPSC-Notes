# Definition
If $\dim(\vec v)$ is even
$$\tilde{v}=\text{sorted}(v)_{dim(v)/2}$$

If $\dim(\vec v)$ is odd
$$\tilde{v}=\mu(\text{sorted}(v)[\lfloor{dim(v)/2}\rfloor],\text{sorted}(v)[\lceil{dim(v)/2}\rceil])$$
# Interpretation
Median is an [[Average]] that shows the "middle-most" value in some [[Collection]] of values
