## Course Description
course about parallel programming, in Erlang

### Learning Objectives
- Parallel Algorithms
	- Describing patterns and individual algorithms
- Parallel Architectures
	- Shared memory, message passing, SIMD arch
	- simple cache coherence protocols
	- Communication Latency and bandwidth limitations
	- differences between bandwidth and inverse latency 
- Parallel Performance
	- Calculating speedup from simple execution models
- Parallel Programming Frameworks
	- Implementing algorithms in erlang and CUDA
	- differences between paradigms
	- identifying when paradigms are best suited for applications
