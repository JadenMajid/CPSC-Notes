# Description
Data consists of Features(columns) and Examples(rows). As a general rule, we should have 10x more examples than features. We should be careful using [[Summary Statistics]], because they can be misleading.
## Types of Data
- Numerical
	- Numbers
- Categorical
	- Nominal
## Cleaning
- Data is often [[Variance|noisy]] and includes irrelevant features and [[Outliers]]
- We want to clean our data to remove irrelevant features
- We can clean with aggregation or binning

# Data Exploration Model
- Simple
	- Collect Data
	- Mine Data for Insights
	- Profit?
- Realistic
	- Learn about process
	- Identify mining task
	- Collect data
	- Clean and preprocess data
	- Choose [[Algorithm]]
	- Mine data
	- Evaluate results & visualize
	- Profit?

## Splitting of Data
Data can be split into 3 main categories. As a general rule, 
- [[Training]] Data
- [[Validation]] Data
- [[Testing]] Data
	- Should be looked at at most once
