# Description
Currently mostly used for image generation. 
- Take training image and add noise to them in a sequence of steps until the image looks like random noise. 
- Train the [[Neural Networks|Neural Network]] to reverse that noise
like a denoising [[Auto Encoder]]. 
- When we want to get an image, start with pure noise, then denoise until an image appears.
